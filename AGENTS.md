# Agent Guidance for Gratis Social

## Visual interpretation tooling

- For browser/UI/visual-parity work, prefer `mcp-for-page-builders` first: https://github.com/juslintek/mcp-for-page-builders
- If `mcp-for-page-builders` is unavailable, use **PinchTab** as the fallback.

---

## Project context

Gratis Social is a WordPress plugin for social share buttons (X, LinkedIn, Facebook, email) with customizable styling and icon sets.

### Key focus areas for agents

- **Button styling** — Icon size, spacing, colors, hover states
- **Social network icons** — Consistent sizing, recognizable branding
- **Button positioning** — Inline, sidebar, floating, sticky placement
- **Responsive behavior** — Button sizing and stacking on mobile
- **Theme compatibility** — Match site colors and typography

### When to use mcp-for-page-builders

- Test button styling across different themes
- Verify icon rendering and sizing consistency
- Check responsive button stacking on mobile
- Test hover/active states for accessibility
- Validate color contrast on dark/light backgrounds
- Check icon alignment with text
